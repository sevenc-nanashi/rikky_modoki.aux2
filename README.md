# rikky_modoki.aux2

[rikky_module](https://hazumurhythm.com/wev/amazon/?script=rikkymodulea2Z)っぽいやつ。

> [!WARNING]
> このプラグインはAviUtl1の互換性のために作られています。
> AviUtl2用に新しくスクリプトを開発する目的では使わないでください。

## 使い方

- `require("rikky_module")`と書いているスクリプトは基本的に動くはずです。
- うまく読み込んでくれない場合は`初期化@rikky_modoki.aux2`をレイヤーの先頭に配置してください。

### オブジェクトサウンド

音声を生成する範囲に「オブジェクトサウンド@rikky_modoki.aux2」を配置し、「音声を更新」を押してください。
対象範囲の映像を順番に評価し、スクリプトから `soundregister` で登録された音声を生成します。

更新ではオブジェクトサウンドの範囲全体の映像がすべてレンダリングされます。
オブジェクトサウンドを細かく分割して配置することで、更新時のレンダリング時間を短縮できます。
